# Theme backups

## Active theme
`../index.css` — Dark Knight noir (steel blue + grey, rain-slick charcoal).

## `stadium-classic.css`
Original gold / pitch-green “night stadium” theme.

### Restore classic stadium
1. Copy `stadium-classic.css` over `../index.css`
2. In `web/index.html`, restore the Google Fonts link to Bebas Neue + DM Sans (see `stadium-classic.index.html.snippet`)
3. Restart Vite if needed
